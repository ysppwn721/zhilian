工作原理

核心不是「让模型改文档」，而是把「哪句该改、改成什么、改动是否可靠」变成可验证的确定性过程。

1
批量导入

创建项目时选一份 Excel 与首批文档；之后可反复「追加文档」，默认单批 50 份、100MB，项目上限 500 份。每批独立成一个 revision 与批次号。

2
识别论断

从 Word/PPT 中定位数值引用、增长率、排名、阈值与原生图表，保留精确字符锚点。

3
确认来源

每条结论关联到 Excel 事实 ID，由人确认。系统给出候选，不代替判断。

4
依赖传播

事实之间可定义派生关系（差额、比率、增长率、合计），改一个数，下游按拓扑序自动重算。

5
确定性核验

用 Decimal 精确计算与单位、口径约束判定状态，不由模型计算。

6
增量修复

按字符区间逆序打补丁，保留未修改内容的格式；PPT 重建原生图表数据系列。

7
独立复核

重新读取生成的文件，验证选中论断已一致、其余正文未变，失败则废弃本次版本。

批量导入是事务性的：一整批文档要么全部解析成功并进入新版本，要么整批回滚， 不会在项目里留下半份文件；重复内容、同名文件与再次上传 Excel 都会被拒绝。

三种运行模式

模式组成适用场景
无模型规则引擎零依赖、零成本、完全离线，默认模式
离线规则 + 本地重排模型内网或断网环境，需安装模型与推理依赖
在线规则 + 本地重排 + API 兜底复杂表述兜底，并提供可读的解释

模型按分层路由出场，而不是整批送出去：规则已能唯一确定来源的论断不调用任何模型； 规则给不出唯一候选时先交本地重排；只有本地模型拒答或零候选才升级到 API， 且单次请求会把困难论断合并成一批（每批最多 40 条）。

无论哪种模式，模型只提建议，不计算、不裁决、不写文件； 所有来源最终仍由使用者确认，计算与写入始终由确定性引擎完成。

工程要点

  • 证据链：每条建议绑定原文片段与事实来源，无依据不下结论
  • 事务性版本：先复制、再写入、复核后原子切换；支持撤销与完整审计记录
  • 格式保真：Word 按 run 级打补丁，未修改文字保持原格式
  • 防篡改：源文件 SHA-256 校验，分析后被外部修改则拒绝操作
  • 提示注入防护：文档内容始终被视为数据，越权指令不影响事实白名单
  • 依赖图：环依赖直接报错，不会静默算出错误结果
  • 大表性能：1999 行事实表解析 0.12 秒（优化前 173 秒）

能力边界（主动公开）

我们把测得的短板写在首页，而不是只放最好看的数字。下面每个数都可用仓库里的脚本复现。

规则擅长什么，不擅长什么

  • 同一批语义只改措辞（销售额→销售收入 / 营收 / 营业总收入），规则 Top-1 由 100% 降到 33.33%，本地语义模型为 94.44%
  • 规则要求文档出现事实表里的那个词；词面对不上时召回为 0，只能转人工
  • 数值计算、单位换算、增长率方向、排名比较集合、阈值口径这些，规则是 100% 且可审计，模型不参与

真实语料上的差距

  • 169 页真实年报：580 个含数字的句子，规则识别出 3 句（0.5%）
  • 瓶颈不只是词表——存在被 PDF 截断的表格残片（如「生物基、淀粉基新材 增加187.44」），这类模型也判不了
  • 下一步是把 PDF 财务表结构化，而不是继续堆正则

评测口径

  • 280 条一致性集：产品真实路径 280/280，但这是封闭夹具自洽性（标签由确定性引擎在环产生），不是行业泛化准确率
  • 该批标签来自双智能体交叉标注，不是真人双标，也不是人工真值
  • 36 份公开年报程序化压力集：本地重排模型 Top-1 96.18%，标签为程序化生成，同样不是人工真值
我们不宣称：不宣称"数据 100% 不出本机"（在线模式会把论断措辞与事实元数据发给模型，但不发送数值，也不发送文件本身）； 不宣称"没有竞品"；不宣称"比企业级产品更准"；不把封闭夹具上的 100% 当作行业准确率。
