# Word 作为事实来源的支持边界

当前知链把 Excel 作为正式事实源，把 Word / PPT 作为论断与成果来源。这样做是为了保证数值、单位、期间和统计口径有稳定的结构化位置，后续变更可以精确回写到单元格。

Word 可以参与事实导入，但采用“候选表格 → 确认 → Excel 正式源”的路径：

1. Word 中必须存在包含完整表头的结构化表格：`事实ID、主体、指标、期间、数值、单位、统计口径`。
2. 表格解析结果先标记为“待确认”，保留 Word 文件名、页/表格位置和原始单元格内容。
3. 用户确认主体、指标、期间、单位和口径后，系统生成标准 Excel 事实表；后续计算、关联和修复使用这份 Excel。
4. Word 普通段落中的数字只作为论断候选，不能自动覆盖事实源；否则容易把叙述性数字、四舍五入数字或不同口径误当成可计算事实。

这样既能接收“事实表在 Word 里”的历史材料，也不会牺牲可审计的单元格定位。后续可增加“从 Word 表格生成候选事实表”按钮，但不建议把普通 Word 文本直接当成事实源。

## 与 PDF 导入的关系

PDF 导入会生成一个正文 Word 和一个事实候选 Excel。正文 Word 用于提取论断，候选 Excel 在确认后成为事实源；原 PDF 只读保留，用于来源页、哈希和复核。
