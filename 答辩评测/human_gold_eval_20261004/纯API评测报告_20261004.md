# 纯 API 在人工 Gold 集上的评测（打乱版）

## 结论

`deepseek-flash` 零样本、无领域微调、无 GPU，在 150 题人工 Gold 集上取得**集合精确匹配 98.67%**，
用 60.1 秒、**¥0.1974**。

| 任务 | 纯 API | 纯规则（同集同口径） | 差值 |
|---|---:|---:|---:|
| 本期引用（quote_current，50 题） | **100.00%** | — | — |
| 上期引用（quote_prior，50 题） | **100.00%** | — | — |
| 增长双来源（growth_set，50 题） | **96.00%** | — | — |
| **整体集合精确匹配（150 题）** | **98.67%** | **77.33%** | **+21.3 点** |

规则基线口径：仅用候选的 `metric` / `period` / `scope` 字段做匹配，
不读文本语义（加不加"口径偏好"结果相同，都是 116/150）。

**+21.3 点就是纯 API 相对"字段匹配"的语义增量。**

## 必须先说明：原集有位置伪影，本结果在打乱集上取得

原 `human_gold_20261004.jsonl` 的候选是构造性排序——先列其他指标，再列同指标错期间，
**最后才是同指标对期间的正例**。实测：

| | 打乱前 | 打乱后 |
|---|---:|---:|
| 总选第 1 个候选 | 18.67% | 14.00% |
| **总选最后 1 个候选** | **70.00%** | 19.33% |
| 随机选一个的期望 | 16.86% | 16.86% |
| 末位基线与随机的差距 | **53.14 点** | **2.47 点** |

- `quote_current` 50 题：末位是正例 **50/50 = 100.0%**
- `quote_prior` 50 题：末位是正例 **50/50 = 100.0%**
- 末位候选 `period` 与正例一致：**150/150 = 100%**

因此**未打乱前，本期/上期两列存在 100% 的"选末尾"捷径**。任何模型在原集这两列上的分数
都无法与"闭着眼睛选最后一个"区分。

打乱方式：每题内部 Fisher-Yates，固定种子 `20261004`；重排 `candidate_position`，
其余字段不动。核验：150 题的候选集合、标签、`fact_text` **0 处不一致**。

对既有数字的影响（以打乱前基线 70% 为尺）：

| 策略 | 本期 Top-1 | 相对 70% 末尾基线 |
|---|---:|---|
| 纯规则 | 52% | −18 点，低于基线 |
| BGE | 78% | +8 点 |
| BERT v2 | 96% | +26 点 |
| 年报修正版 BERT | 68% | **−2 点，低于基线** |
| BGE + BERT 等权 RRF | 70% | **0 点，恰等于基线** |
| 固定任务路由 | 78% | +8 点 |

**该表是打乱前的，不可与本文的 98.67% 直接比较**——各模型需要在打乱集上重测。

## 通道问题：此前 API 调用失败的根因

`human_gold_api_error.json` 记录 256 ms、0 token、`response_status: null`。实测根因：

> `deepseek-flash` 同时输出 `content` 与 `reasoning_content`，**推理 token 计入 `max_tokens`**。
> `max_tokens=20` 时推理段吃掉全部额度，`content` 为空字符串，
> 调用方拿不到结构化输出即判"返回结构无效"。

本次 `max_tokens=4096`，150 次调用**全部返回合法 JSON**（`parse_modes: {"json": 150}`），
失败请求 0。

## 过程记录：一次 prompt 规格修正带来 +6.7 点

首轮 92.00%（增长题 78.00%）。逐题分析 12 道错题：**11 道是"部分对（缺或多）"**，其中

- 6 道：增长类论断只返回了本期，漏掉上期来源
- 4 道：多选了指令里顺带提到的其他指标
- 1 道：用了同义指标名（`营业收入金额` 而非 `营业收入`）

**根因是 prompt 未声明"变化/增长类论断同时依赖本期与上期两条来源"**——是规格缺失，不是能力不足。
补上该规则并要求"只选指令真正指向的指标，不连带选择顺带提到的其他指标"后：

| | 首轮 | 修正后 |
|---|---:|---:|
| 整体 | 92.00% | **98.67%** |
| 本期 | 100.00% | 100.00% |
| 上期 | 98.00% | 100.00% |
| 增长 | 78.00% | **96.00%** |

## 剩余 2 道错题

| 题号 | 指令 | gold | 预测 | 性质 |
|---|---|---|---|---|
| SR-111 | 全年实现营业收入34,207.47 万元，同比增长5.93% | `营业收入` 本期+上期 | `营业收入金额` 本期+上期 | 同义写法，Gold 判为不同指标 |
| SR-143 | 报告期内，公司实现营业收入22.65 亿元，同比减少19.78%，…净利润2.17… | `营业收入` 本期+上期 | 多选了 `归属于上市公司股东的净利润` | 指令顺带提到净利润，模型连带选中 |

两道都属**指标名归一化**问题，不是期间或口径判断错误。

## 本任务的边界（不可外推）

- 题干是**检索式指令**（「请核对公司本期披露的营业收入对应的事实来源。」），
  不含数值，模型只需判断指令指向哪个 `metric` + `period` + `scope`。
- 因此本任务测的是**指令理解 + 期间/口径判别**，
  **不等于数值核验**（如"公司披露营业收入 X 元"是否为真）。
- 候选的 `fact_text` 由程序从 PDF 抽取，仍是弱标注；150 题人工 Gold 的标签经人工确认，
  但事实侧的抽取误差未单独度量。
