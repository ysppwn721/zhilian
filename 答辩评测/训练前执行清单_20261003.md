## 人工审阅顺序

优先审阅 71 条审阅表中的：

1. 三值校验为 `consistent` 的增长率句，先确认本期值、增长率和指标是否属于同一主体。
2. 有明确单位声明的记录，优先于单位仅从正文推断的记录。
3. 有“合并财务报表”“母公司财务报表”“分部信息”等明确口径的记录。
4. 上期来源候选，目标让本期/上期接近 1:1，避免“总选本期”捷径。
5. 复合指标和同义词记录一律先标 `review` 或 `abstain`，不得凭字符串相似直接接受。

每条记录至少填写：

- `人工判定`：`accept` / `reject` / `abstain`；
- `口径确认(合并/母公司/分部)`；
- `单位确认(元/万元)`；
- `判定人`、`判定时间`、`备注`。

校验命令：

```powershell
.\\.venv\\Scripts\\python.exe 答辩评测\\validate_review_sheet_v2.py
```

只有校验结果中 `ready_for_label_promotion=true`，才允许生成带标签的数据。

## 训练数据目标结构

每条论断至少构造 3 个候选事实：

- 1 个正确来源；
- 1 个错指标或相近指标；
- 1 个错期间、错主体/口径或无来源候选。

增长率论断必须使用来源集合 `{本期事实, 上期事实}`，评价指标使用集合完整率和集合精确匹配率，不能把它压成单一 Top-1 标签。

建议的最小划分：

| 划分 | 论断数 | 独立公司数 | 约束 |
| --- | ---: | ---: | --- |
| train | 300+ | 40+ | 可包含语义改写，但改写回指原句 |
| dev | 100+ | 10+ | 用于早停和阈值校准 |
| test | 200+ | 15+ | 公司完全隔离，不调参 |

## 模型对照

训练前必须固定以下对照：

1. 规则候选排序；
2. 未微调中文基础模型的冻结相似度；
3. 冻结主干、仅训练分类头；
4. 微调后的 4 层中文候选模型；
5. 现有 BGE reranker。

报告 Top-1、候选覆盖率、错误关联率、歧义拒答率、来源集合完整率，以及 CPU 延迟和模型体积。弃答不计作错误关联，但要单独报告覆盖率下降。

## 正式训练闸门

以下条件必须同时满足：

- `company_leakage_between_splits` 不存在；
- `frozen_evaluation_source_reused_for_training` 不存在；
- “总选本期”在 test 不得满分；
- 主体、单位、期间和口径审计通过；
- train/dev/test 均有已确认标签；
- 评测集包含真实上期来源和拒答样本；
- 公开数据集只作为通用语义预适配或拒答辅助，不冒充本项目任务指标。
