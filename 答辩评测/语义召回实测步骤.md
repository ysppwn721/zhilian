# 语义论断抽取智能体实测步骤

## 公网演示测试（推荐）

公网演示的 API Key 只应放在服务器 `/opt/zhilian/biaoliruyi/.env`，浏览器和本机不需要 Key。

服务器执行：

```bash
cd /opt/zhilian/biaoliruyi
grep -E '^(DEEPSEEK_API_KEY|ZHILIAN_LLM_MODE|ZHILIAN_SEMANTIC_RECALL)=' .env \
  | sed -E 's/^DEEPSEEK_API_KEY=.*/DEEPSEEK_API_KEY=<configured>/'
```

确认配置如下：

```env
ZHILIAN_LLM_MODE=hybrid
ZHILIAN_SEMANTIC_RECALL=1
```

修改后重启：

```bash
systemctl restart zhilian
systemctl status zhilian --no-pager
```

然后打开 `https://demo.zhilian.space/`，点击“体验演示”，再运行智能体。演示项目已经使用 `semantic=1` 创建，正文中包含：

```text
公司本期实现营收125万元。
```

预期在“变更与核验记录 → 智能体执行轨迹”中看到：

```text
抽取智能体 · 语义候选召回
关联智能体 · DeepSeek 建议 或 关联智能体 · 本地 BGE
模型台账：远程调用次数、token、耗时
```

语义候选只做预览，不会自动确认来源，也不会自动修改 Office 文件。

## 本机隔离测试

本机没有 `.env` 时不会有 API Key，这是有意的安全默认值。配置当前 shell 后运行：

```powershell
$env:DEEPSEEK_API_KEY = '<服务端测试密钥>'
$env:ZHILIAN_LLM_MODE = 'hybrid'
$env:ZHILIAN_SEMANTIC_RECALL = '1'
.\.venv\Scripts\python.exe '答辩评测\run_semantic_recall_live.py'
```

脚本使用隔离演示工作区，输出报告后删除临时 Office 文件，不会修改正式项目。
