# 办公文件规模压力测试

更新时间：2026-09-26

## 测试设计

通过真实 HTTP 导入与追加接口构造一份 Excel、一个 24 页 PPT，以及 100 份 Word 文档。Word 文档分批追加，单批不超过 50 份；测试同时覆盖文件解析、项目状态复制、批次提交和论断汇总。

复现命令：

```powershell
.\.venv\Scripts\python.exe 答辩评测/run_office_scale_stress.py
```

## 结果

| 指标 | 结果 |
| --- | ---: |
| Excel 数据源 | 1 份 |
| Word 文档 | 100 份 |
| PPT 页数 | 24 页 |
| 项目总文件数 | 103 份（Excel + 100 Word + 1 PPT + 初始 Word） |
| PPT 识别论断 | 24 条 |
| Word 识别论断 | 100 条 |
| 追加批次 | 3 批 |
| 总耗时 | 11.698 秒 |
| 状态 | PASSED |

批次耗时分别为 4.264 秒、2.775 秒和 2.135 秒。结果文件保存在 `答辩评测/office_scale_stress_results.json`。

## 结论与边界

当前“一个 Excel 对多份 Word/PPT”的追加链路已经通过 24 页与 100 份文件的合成压力测试，项目默认总文档上限为 500 份，单批追加上限为 50 份、100 MB。该测试验证的是结构化文本和批量事务处理，不等于任意真实 PPT 排版都能无损解析；图片文字、母版、备注、组合对象和复杂图表仍按系统提示转人工复核。
