# v3 人工 Gold 子集复测报告

日期：2026-10-05

## 数据范围

盲复核表共 40 条：19 条本期单值题、18 条增长双来源题、3 条无法确认而拒答的题。拒答题保留在审计记录中，不计入模型正确率。所有已选事实 ID 均通过候选集合校验，人工 Gold 不使用原程序标签作为评分依据。

产物：

- `human_gold.jsonl`：37 条可评分题的候选及人工来源标签
- `review_audit.json`：40 条复核决定、拒答和校验结果
- `manifest.json`：数据规模与标签来源说明

## 结果

候选顺序打乱后，BGE 与年报修正版 BERT 的预测集合均保持 100% 一致。年报修正版 BERT 本次 CPU 运行约 30.7 秒，BGE 约 10.1 秒；两者模型规模、运行时和硬件不同，耗时只作记录，不能直接作为性能排名。

## 解释与边界

本次结果说明年报修正版 BERT 在这批真实年报人工复核样本上比通用 BGE 有明显增量，适合继续作为“年报模式”的可选本地候选。它仍是 `bert-base-chinese` 的二分类重排器，不是生成式大模型，也不负责抽取、计算或写回。

样本只有 37 条可评分题，且来自当前 v3 盲复核子集，不能表述为所有行业或所有文档类型的准确率。正式接入前仍需完成更大人工 Gold、低置信度阈值、拒答准确率和 CPU 内存验收；在这些条件完成前，默认线上模型仍为规则 + BGE + API/人工兜底。
