# 三层路由丢分层分析

## 修复前

修复前三层路由在 37 条人工 Gold 上有 3 条错误：

| 论断 | 路由层 | 表现 | 根因 |
|---|---|---|---|
| `v3-000916-0201` | abstain | 没有选出经营活动产生的现金流量净额 | 正文简称“现金流净额”未纳入受控指标别名，且年报 BERT 把同页收益率候选排在前面 |
| `v3-002663-0233` | API | 增长题只返回上期来源 | 每股收益事实的单位列被抽成“元”，本期来源被证据门控拒绝，双来源完整性未补齐 |
| `v3-002932-0151` | annual_bert | 把 `2016年` 当作上期来源 | 显式年份没有按报告年份归一化，历史年份槽位判断过宽 |

规则层在修复前没有出现错误；主要问题集中在模型结果进入证据门控后的归一化和完整性检查。

## 修复后

本轮加入：

- “经营活动产生的现金流净额”等受控指标简称；
- “元”到“元/股”的每股收益量纲归一化，同时继续拒绝收益率与金额的冲突；
- 显式年份与报告年、报告年前一年之间的期间槽位映射；
- 增长题同指标、同口径、双期间唯一候选的完整性补全；
- 同一句包含多个指标时按正文指标出现位置稳定选择。

结果：36 条由规则处理、1 条由年报 BERT 处理、0 条进入 API、0 条拒答；单值 Top-1 和增长集合精确匹配均为 100%。

该结果只证明本批人工 Gold 上的路由门控修复有效。新增文档遇到无法唯一证明的指标、单位或期间时，仍应升级到模型/API或拒答。
