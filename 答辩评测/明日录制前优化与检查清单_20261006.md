# 明日录制前优化与检查清单

## 当前判断

代码回归测试已通过：364 passed，1 warning。软件设计书已完成第七页字体、封面作品形态和文字删除修订。

明天录制前不再继续训练模型，也不再扩展 PDF 修改功能。当前最需要解决的是演示稳定性和材料口径统一。

## P0 必须完成

### 1. 固定一条可重复的离线演示链路

录制主流程使用“体验演示项目”，顺序固定为：

1. 启动服务并登录；
2. 上传或打开演示项目；
3. 展示 Excel 事实源与 Word/PPT 原文；
4. 点击“载入演示变更”；
5. 点击“更新数据并验证”；
6. 展示影响范围、失效论断和来源位置；
7. 运行智能体，展示准备、关联、诊断和人工确认节点；
8. 预览修复，批准部分修复；
9. 下载新版 Word/PPT 和审计报告；
10. 重新打开结果，展示复核通过、版本记录和撤销能力。

录制时以离线规则和本地能力为主，API 只作为可选分支。这样即使网络或密钥不可用，主视频仍能完整结束。

### 2. 统一评测数字

视频可以引用的最新数字必须带数据边界：

- 37 条人工 Gold 可评分论断：自动年报画像路由 100% 单值 Top-1、100% 增长集合精确匹配；路由分布为规则 36、年报 BERT 1、API 0、拒答 0。
- 这组数字是人工 Gold 小样本的工程验证，不能表述为行业准确率。
- 程序化 v3 弱标签全量结果：年报修正版 BERT 单值 93.33%、增长集合精确匹配 81.36%、增长 F1 90.51%。这组数字只能作为模型开发集结果。
- 纯 API 的 94.74%/98.59% 是另一项 37 条同集实测，不能与自动路由的 100% 混成同一项结果。

视频中不要继续使用旧 PPT 的 86.8%、71.4%、96.18% 等旧口径，除非明确标注为历史对照。

### 3. 检查录制环境

- 确认 `http://127.0.0.1:8765` 可以打开；
- 确认演示账号可登录；
- 确认浏览器缩放为 100% 或 110%，侧栏、来源抽屉和修复预览不被裁切；
- 关闭无关窗口、通知和命令行中的密钥；
- 确认工作区有写权限，能下载成果包；
- 若展示本地模型，先在健康状态中确认模型已加载；若未加载，改为展示“规则 + 人工确认”的离线模式，不临时下载模型。

当前 Windows 安装包没有内置年报 BERT 权重。若要在开发工作区展示年报模型，应在启动服务前确认类似下面的本地配置已生效；录制安装包时则把它作为可选研究能力，不把它说成安装包默认能力：

```powershell
$env:ZHILIAN_ANNUAL_RERANKER_ENABLED = "1"
$env:ZHILIAN_ANNUAL_RERANKER_PATH = "C:\Users\Administrator\Desktop\华北五省设计\models\zh_reranker_bert_annual_repaired_v1_onnx_compat"
```

健康状态必须显示年报模型已启用，且智能体轨迹中出现年报画像选择；否则按规则离线流程录制。

## P1 建议在录制前完成

### 4. 更新 PPT 的演示文案和图表

旧 PPT 的模型评测页与最新报告不一致，应替换为以下三层表述：

- 规则层：处理字段、期间、单位、口径和数值关系能够唯一证明的论断；
- 年报 BERT：只对年报文档中规则无法唯一确认的候选进行离线排序；
- DeepSeek API：只在本地证据不足时作为可选兜底，返回结果仍需经过确定性门控和人工批准。

图表标题建议使用“任务感知路由：规则、本地模型与 API 的职责分工”，不要使用“模型全面领先”或“整体准确率 100%”。

### 5. 准备三张必需画面

录制至少保留以下画面：

1. 影响范围：Excel 数值变化后，Word/PPT 中受影响论断的数量和位置；
2. 智能体轨迹：准备 → 关联 → 诊断 → 询问 → 修复 → 复核；
3. 修复前后：Word 正文、PPT 图表、审计记录和版本号同时展示。

模型评测图、费用图和延迟图放在答辩材料中，视频主线优先展示产品闭环。

## 不要在录制前做的事情

- 不要重新训练或更换默认模型；
- 不要把年报 BERT 的 PyTorch 或 INT8 研究权重临时塞进安装包；当前安装包的本地模型属于可选能力；
- 不要在视频中演示直接改写 PDF；PDF 当前只读提取并转为可编辑 Office 产物；
- 不要把 37 条人工 Gold 的 100% 写成普遍准确率；
- 不要把“规则层 100%”写成整套模型准确率，规则只对它实际唯一证明的样本负责；
- 不要现场依赖 API 才能完成主流程。

## 现场答辩的三句话

1. “模型只提出来源候选，数值计算、单位换算、期间和口径校验由程序完成，写回前还要经过用户批准。”
2. “年报 BERT 是按真实上市公司年报训练的专用候选模型；文档画像识别为年报时才选择它，否则回退通用本地模型。”
3. “无法唯一证明的内容系统会拒答并保留人工入口，因此交付的是可追溯的证据链，而不是无条件自动改文件。”

- 视频中没有出现 API Key、服务器密码或本地绝对路径；
- 视频中的数字与设计文档、PPT、评测报告一致；
- 下载成果包可以重新打开；
- 变更记录包含来源确认、修复批准和复核结果；
- 安装包、源代码、软件设计书、作品简介和测试证据都位于最终提交包中；
- 提交包 SHA256 校验文件在最后一次修改后重新生成。
